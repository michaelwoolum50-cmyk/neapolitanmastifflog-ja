# NeapolitanMastiffLog（Neo Book）— ナポリタン・マスティフ専用日記アプリ

投稿者: michaelwoolum

ナポリタン・マスティフ（マスティーノ・ナポレターノ）のためだけに作られた飼育記録アプリです。古代ローマのモロッサーの血を引く、イタリアの由緒ある番犬のための記録ノート。大きな骨格、立派なデューラップ（首元のたるみ）、深い顔のしわ、そして家族を穏やかに見守る性質を記録するために設計されました。

**短い説明:** ナポリタン・マスティフ専用日記：しわケア、番犬記録、イタリア血統の管理。

## できること

- 🐕 ネオ名簿と体格の記録 — 体重、デューラップの発達、毛色（ブルー／グレー、ブラック、フォーン、マホガニー）、頭回り、血統メモ
- 🧼 顔のしわと衛生ケアの記録 — 深い顔のひだの清掃、湿気対策、耳の衛生、皮膚のひだの健康状態を毎日記録
- 🛡️ 番犬と見回りの記録 — 番犬としての勤務、穏やかな縄張りの見張り、敷地の見回りメモ
- 🏛️ イタリア・マスティーノの血統 — 古代ローマの伝統、ヴェスヴィオの血統、犬舎の登録番号、血統書の保存
- 📸 プライベート写真ギャラリー — 写真は端末の中だけに保存（カメラ撮影・ギャラリー取り込み対応）
- 🔒 PINロックと誤削除防止の確認機能
- 📴 完全オフライン — 保存は100%端末内。アカウント不要、クラウドなし、トラッキングなし

無料アプリです（広告が含まれます）。
